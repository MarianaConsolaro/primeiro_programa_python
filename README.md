## 📚 Sobre o projeto

Este repositório foi desenvolvido como parte da disciplina
**Inteligência Artificial e Programação para Engenharia**.

Este é meu primeiro projeto utilizando a linguagem Python,
representando o início da minha jornada no desenvolvimento
de soluções computacionais e no aprendizado de programação.

## 🎯 Objetivos

- Conhecer a linguagem Python.
- Aprender conceitos fundamentais de programação.
- Desenvolver a lógica computacional.
- Praticar a criação e execução de códigos no VS Code.
- Conhecer ferramentas de versionamento com Git e GitHub.
